# Student Management System Using Microservices

## Project Overview

This project implements a Student Management System using
independent microservices, containerization, and automated CI/CD.

## Microservices

1. Student Service
2. Course Service
3. Result Service

## Technologies

- Python
- FastAPI
- Docker
- Docker Compose
- PostgreSQL
- GitHub
- GitHub Actions
- Docker Hub

## Project Objectives

- Design independent REST API services.
- Containerize the services using Docker.
- Integrate the application with a database.
- Automate testing and container image publishing.
- Verify the application through functional tests.
